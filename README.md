# Chhatrapati Shivaji Maharaj Webpage

A responsive, interactive, and informative website dedicated to the life, achievements, administration, military campaigns, and legacy of Chhatrapati Shivaji Maharaj.

## Live Demo

Visit the website:
https://sanjanawandre.github.io/Chhatrapati-Shivaji-Maharaj-Webpage/

## Features

* Responsive design for desktop, tablet, and mobile devices
* Modern and user-friendly interface
* Historical information about Chhatrapati Shivaji Maharaj
* Interactive navigation
* Animated scrolling effects
* Timeline of important events
* Multimedia content and images
* Accessible and easy-to-read layout

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
.
├── index.html

```

## Purpose

This project was developed to present the history, achievements, and lasting impact of Chhatrapati Shivaji Maharaj through an engaging web experience. The website serves as an educational resource while demonstrating front-end web development skills.

## Learning Outcomes

Through this project, I gained experience in:

* Responsive web design
* Front-end development using HTML, CSS, and JavaScript
* Website deployment using GitHub Pages
* User interface design
* Content organization and presentation

## Deployment

The website is hosted using GitHub Pages and can be accessed online through the live demo link above.
